## Cài đặt thư viện

Project sử dụng các thư viện chính sau:

- `customtkinter` — xây dựng giao diện GUI
- `opencv-python` — xử lý ảnh và camera
- `numpy` — xử lý ma trận ảnh
- `pillow` — chuyển đổi và hiển thị ảnh trên Tkinter

### Cài tất cả thư viện

Mở Terminal tại thư mục project và chạy:

```bash
pip install customtkinter opencv-python numpy pillow matplotlib
